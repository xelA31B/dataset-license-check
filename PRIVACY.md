# Privacy Policy — Dataset License Check

_Last updated: 13 November 2026_

This plugin is a set of instructions (skills) that runs inside Claude. It has no servers of its own.

- **No data collection.** The plugin author does not receive, store or process any data or reports.
- **Public lookups.** To check an item, Claude reads public pages such as Hugging Face cards, licence texts and project pages, using its web search and fetch tools. Only public identifiers (dataset or model names) are used in these lookups.
- **Your files.** If you point the plugin to project files to build a register, Claude reads them within your session; nothing is sent elsewhere by the plugin.
- **No tracking, cookies or analytics.**

Questions: https://github.com/xelA31B/dataset-license-check/issues
