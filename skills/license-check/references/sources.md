# Free public sources

| Source | Where | Use |
|---|---|---|
| Hugging Face Hub — datasets | Page: `https://huggingface.co/datasets/<id>` · API: `https://huggingface.co/api/datasets/<id>` | `cardData.license`, tags (`license:…`), gated status, card text with sources and terms |
| Hugging Face Hub — models | Page: `https://huggingface.co/<id>` · API: `https://huggingface.co/api/models/<id>` | Licence, base model, datasets used, gated status, use policy |
| SPDX License List | `https://spdx.org/licenses/` | Standard identifiers and full texts |
| Open Source Initiative | `https://opensource.org/licenses` | Approved open-source licences |
| Creative Commons | `https://creativecommons.org/licenses/` | CC licence terms (BY, SA, NC, ND) |
| Data Provenance Initiative | `https://www.dataprovenance.org` | Audited provenance and licence findings for popular datasets |
| Papers and repositories | arXiv, GitHub, project sites | Collection method, sources, terms of use |
| EU AI Act Service Desk | `https://ai-act-service-desk.ec.europa.eu` | Obligations for general-purpose AI model providers: copyright policy, public summary of training content (verify current guidance and template) |

Notes:
- The Hub API is public for public repositories; gated repositories show metadata but require accepting terms to access files.
- Licence fields on the Hub are self-declared by the publisher; always check the card and the licence text.
