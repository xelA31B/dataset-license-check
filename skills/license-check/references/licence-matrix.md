# Licence matrix (orientation — always read the actual terms)

| Licence family | Commercial use | Training / fine-tuning | Redistribution | Main obligations / limits |
|---|---|---|---|---|
| Public domain / CC0 | Yes | Yes | Yes | None (check third-party content) |
| CC BY | Yes | Generally yes | Yes | Attribution |
| CC BY-SA | Yes | Generally yes; derivative sharing debated | Yes, same licence | Attribution, share-alike for adapted material |
| CC BY-NC (-SA/-ND) | **No** | Non-commercial only | Non-commercial only | Attribution; ND forbids adaptations |
| ODC-By / ODbL | Yes | Yes | Yes | Attribution; ODbL share-alike for databases |
| MIT / BSD / Apache-2.0 (code, some data and models) | Yes | Yes | Yes | Notice; Apache: patent grant, NOTICE file |
| GPL / AGPL (code) | Yes | Debated for training | Yes, copyleft | Copyleft for distributed derivatives; AGPL network use |
| OpenRAIL / RAIL variants (models) | Usually yes | Usually yes | Yes, with use restrictions passed on | Use-based restrictions must flow to downstream users |
| Custom model licences (vendor community licences) | Often yes with limits | Varies; some forbid improving other models | Varies | User or revenue thresholds, naming, acceptable-use policy, output clauses |
| "Research only" / no licence | **No** | Research only / unclear | **No** | Treat as not usable commercially |

Provenance checks that override a permissive label:
- Content scraped from sites whose terms forbid it, or copyrighted works without permission
- Personal data without a lawful basis (GDPR) — relevant for EU use
- Synthetic data generated by a model whose terms restrict using outputs to train other models
- Upstream dataset or base model with a stricter licence than the derivative claims
